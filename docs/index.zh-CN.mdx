# 从 MDX 目录直接生成文档网站

Doctrine 可以把一个 MDX 目录转换成静态 React 文档网站。开发环境由 Vite SSR 驱动，内容编译则复用 `@amamo/mdx`。

[开始使用](/zh-CN/guide/getting-started/)。

## 第一期功能

- 开发阶段使用 Vite SSR，构建阶段输出静态 HTML
- 支持多语言路由和元数据
- 使用 Pagefind 进行全文搜索
- 支持亮色和暗色主题
- 可部署到 `/doctrine/` 这样的子路径
