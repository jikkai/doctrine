# 配置参考

Doctrine 不依赖配置文件。当默认值不够用时，在项目根目录添加 `doctrine.config.ts`：

```ts
import { defineConfig } from '@amamo/doctrine'

export default defineConfig({
  title: {
    en: 'Acme documentation',
    'zh-CN': 'Acme 文档',
  },
  description: {
    en: 'Product guides and API notes.',
    'zh-CN': '产品指南和 API 说明。',
  },
  siteUrl: 'https://docs.example.com/',
  githubUrl: 'https://github.com/acme/docs',
  copyright: {
    en: 'Copyright © 2026 Acme.',
    'zh-CN': '版权所有 © 2026 Acme。',
  },
  iconLibrary: 'lucide-react',
  outDir: 'dist',
  locales: {
    default: 'en',
    names: ['en', 'zh-CN'],
    labels: { en: 'English', 'zh-CN': '简体中文' },
  },
  components: './docs/components.tsx',
  styles: './docs/theme.css',
})
```

Doctrine 也识别 `doctrine.config.mts`、`doctrine.config.js` 和 `doctrine.config.mjs`。

## 网站选项

| 选项          | 类型                               | 默认值                            | 用途                           |
| ------------- | ---------------------------------- | --------------------------------- | ------------------------------ |
| `title`       | `string \| Record<string, string>` | `"Documentation"`                 | 网站标题和页面 title 后缀。    |
| `description` | `string \| Record<string, string>` | `"Documentation built from MDX."` | 默认页面描述。                 |
| `siteUrl`     | `string`                           | `"http://localhost/"`             | 绝对公开 URL 和部署 base。     |
| `githubUrl`   | `string`                           | 无                                | 顶部 GitHub 图标指向的链接。   |
| `copyright`   | `string \| Record<string, string>` | 无                                | Footer 中可本地化的版权文案。  |
| `iconLibrary` | `string`                           | 无                                | 提供导航图标命名导出的包。     |
| `outDir`      | `string`                           | `"dist"`                          | 相对项目根目录的静态输出目录。 |
| `locales`     | `IDoctrineLocaleConfig`            | 仅英语                            | 多语言路由和显示名称。         |
| `components`  | `string`                           | 无                                | 自定义 MDX 组件模块路径。      |
| `styles`      | `string`                           | 无                                | 自定义主题或样式表路径。       |

`--site-url` 和 `--out-dir` 可以为单次构建覆盖配置文件中的值。

`outDir` 必须位于项目根目录内，同时不能位于 MDX 内容目录内。构建写入文件前会清空输出目录。

## 目录导航

每个包含 MDX 的目录都要为对应 locale 提供一个 `meta` 导航文件。`meta.ts` 属于默认 locale，其他语言使用 `meta.zh-CN.ts` 这样的文件名。数组顺序就是侧栏顺序：

```ts
// docs/meta.zh-CN.ts
import { defineDirectory } from '@amamo/doctrine'

export default defineDirectory({
  items: [
    { page: 'index', title: '概览', icon: 'House' },
    { directory: 'guide' },
    { page: 'configuration', title: '配置', icon: 'Settings' },
  ],
})
```

子目录自行配置它在父级显示的分组文案、图标和直属内容：

```ts
// docs/guide/meta.zh-CN.ts
import { defineDirectory } from '@amamo/doctrine'

export default defineDirectory({
  title: '指南',
  icon: 'BookOpen',
  items: [{ page: 'install', title: '安装', icon: 'PackagePlus' }],
})
```

`page` 是不包含扩展名和 locale 后缀的直属 MDX 文件名；`directory` 是直属子目录。对应语言的每个页面和子目录都必须出现且只能出现一次。遗漏、重复和不存在的引用都会让构建失败。

图标是可选的。只要导航使用了图标，就要把 `iconLibrary` 指向一个以命名导出提供 React 图标组件的包。Doctrine 只为实际配置的图标生成静态导入。

MDX 不要求 frontmatter。仍可选填字符串类型的 `description` 作为页面描述；未提供时使用网站 description。

## 多语言

`locales.default` 必须包含在 `locales.names` 中；locale 不能重复；名称只能由字母、数字和以连字符分隔的片段组成。

```ts
locales: {
  default: "en",
  names: ["en", "zh-CN", "ja"],
  labels: {
    en: "English",
    "zh-CN": "简体中文",
    ja: "日本語",
  },
}
```

通过文件名后缀创建翻译：

```text
docs/guide/install.mdx       → /guide/install/
docs/guide/install.zh-CN.mdx → /zh-CN/guide/install/
docs/guide/install.ja.mdx    → /ja/guide/install/
```

与它们对应的导航文件分别是 `docs/guide/meta.ts`、`docs/guide/meta.zh-CN.ts` 和 `docs/guide/meta.ja.ts`。不带后缀的配置属于默认 locale；带后缀的配置只作用于具有相同 locale 后缀的 MDX，不会回退到其他语言的导航配置。

只有另一个已配置 locale 中存在相同 slug 的文件时，页面才会显示语言按钮。

## 自定义 MDX 组件

用 `components` 指定相对项目根目录的模块路径：

```ts
export default defineConfig({
  components: './docs/components.tsx',
})
```

该模块必须默认导出组件映射：

```tsx
import type { IDoctrineComponents } from '@amamo/doctrine'
import type { ReactNode } from 'react'

function Callout({ children }: { children: ReactNode }) {
  return (
    <aside className="rounded-lg border border-sky-500 bg-sky-50 p-4 dark:bg-sky-950">
      {children}
    </aside>
  )
}

export default { Callout } satisfies IDoctrineComponents
```

在 MDX 中直接使用注册名：

```mdx
<Callout>部署前先执行迁移。</Callout>
```

该模块会同时进入 SSR 和浏览器 bundle，因此组件必须能在构建阶段的 Node.js 环境中渲染。浏览器专属全局变量应放在 effect 或事件处理函数中使用，不能在模块加载或组件渲染时访问。Tailwind 会自动扫描组件文件。

自定义条目可以覆盖同名的内置 MDX 元素映射。例如，注册 `a` 会替换 Doctrine 默认的链接渲染器。

主题变量、内置组件和包装覆盖示例见[自定义](/zh-CN/customization/)。
