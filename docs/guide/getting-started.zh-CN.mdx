# 入门教程

这份教程从空项目开始，最终会在 `dist` 中得到可以直接部署的静态网站。

## 1. 安装 Doctrine

Doctrine 需要 Node.js 20.19 或更高版本。在文档所属项目中安装：

```sh
pnpm add @amamo/doctrine
mkdir docs
```

项目最少只需要这些文件：

```text
my-project/
├── docs/
│   ├── meta.ts
│   └── index.mdx
└── package.json
```

## 2. 编写首页

创建 `docs/index.mdx`：

```mdx
# Acme 文档

从导航中选择一篇指南。
```

创建 `docs/meta.ts`，用数组配置导航文案、图标和顺序：

```ts
import { defineDirectory } from '@amamo/doctrine'

export default defineDirectory({
  items: [{ page: 'index', title: 'Acme documentation' }, { directory: 'guide' }],
})
```

再添加 `docs/guide/install.mdx`：

````mdx
# 安装 Acme

```sh
pnpm add acme
```
````

在同级的 `docs/guide/meta.ts` 中配置这个目录：

```ts
import { defineDirectory } from '@amamo/doctrine'

export default defineDirectory({
  title: 'Guide',
  items: [{ page: 'install', title: 'Install Acme' }],
})
```

该文件对应 `/guide/install/`。

## 3. 启动开发服务器

```sh
pnpm exec doctrine dev docs
```

默认地址是 `http://localhost:5173`。修改 MDX 文件或就近的导航配置后，网站无需重启即可更新，搜索索引也会随之重新生成。

需要其他 host 或端口时：

```sh
pnpm exec doctrine dev docs --host 0.0.0.0 --port 4173
```

## 4. 添加网站元数据

在项目根目录创建 `doctrine.config.ts`：

```ts
import { defineConfig } from '@amamo/doctrine'

export default defineConfig({
  title: 'Acme 文档',
  description: 'Acme 的产品指南和 API 说明。',
  iconLibrary: 'lucide-react',
})
```

只有导航使用图标或网站需要其他选项时，根配置文件才是必需的。没有配置时，Doctrine 使用 `Documentation` 作为网站标题，并只启用 `en` locale。

## 5. 构建静态文件

构建时提供最终公开网址：

```sh
pnpm exec doctrine build docs --site-url https://docs.example.com/
```

Doctrine 会把静态 HTML、客户端资源、404 页面和 Pagefind 索引写入 `dist`：

```text
dist/
├── 404.html
├── assets/
├── guide/install/index.html
├── index.html
└── pagefind/
```

仓库网站需要在 URL 中包含仓库路径：

```sh
pnpm exec doctrine build docs --site-url https://user.github.io/acme/
```

产物仍直接写入 `dist`。Doctrine 会把 `/acme/` 应用到公开 URL，而不是创建 `dist/acme`。
