# Getting started

This tutorial starts with an empty project and ends with a deployable static site in `dist`.

## 1. Install Doctrine

Doctrine requires Node.js 20.19 or newer. Install it in the project that owns the documentation:

```sh
pnpm add @amamo/doctrine
mkdir docs
```

Your project now needs only this structure:

```text
my-project/
├── docs/
│   ├── meta.ts
│   └── index.mdx
└── package.json
```

## 2. Write the home page

Create `docs/index.mdx`:

```mdx
# Acme documentation

Choose a guide from the navigation.
```

Create `docs/meta.ts`. The array owns the navigation title, icon, and order:

```ts
import { defineDirectory } from '@amamo/doctrine'

export default defineDirectory({
  items: [{ page: 'index', title: 'Acme documentation' }, { directory: 'guide' }],
})
```

Add another page at `docs/guide/install.mdx`:

````mdx
# Install Acme

```sh
pnpm add acme
```
````

Configure that directory beside its MDX in `docs/guide/meta.ts`:

```ts
import { defineDirectory } from '@amamo/doctrine'

export default defineDirectory({
  title: 'Guide',
  items: [{ page: 'install', title: 'Install Acme' }],
})
```

That file is available at `/guide/install/`.

## 3. Start the development server

```sh
pnpm exec doctrine dev docs
```

The default address is `http://localhost:5173`. Changes to MDX files and nearby navigation metadata
update the site without restarting the server, and search is rebuilt when either changes.

Use another host or port when needed:

```sh
pnpm exec doctrine dev docs --host 0.0.0.0 --port 4173
```

## 4. Add site metadata

Create `doctrine.config.ts` at the project root:

```ts
import { defineConfig } from '@amamo/doctrine'

export default defineConfig({
  title: 'Acme documentation',
  description: 'Product guides and API notes for Acme.',
  iconLibrary: 'lucide-react',
})
```

The root config is optional unless the navigation uses icons or the site needs other options.
Without it, Doctrine uses `Documentation` as the site title and `en` as the only locale.

## 5. Build static files

Pass the final public URL to the build:

```sh
pnpm exec doctrine build docs --site-url https://docs.example.com/
```

Doctrine writes static HTML, client assets, a 404 page, and the Pagefind index to `dist`:

```text
dist/
├── 404.html
├── assets/
├── guide/install/index.html
├── index.html
└── pagefind/
```

For a repository site, include its pathname:

```sh
pnpm exec doctrine build docs --site-url https://user.github.io/acme/
```

The output still goes directly into `dist`; Doctrine applies `/acme/` to public URLs instead of
creating `dist/acme`.
