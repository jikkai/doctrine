# Documentation from MDX, without a framework-shaped project

Doctrine turns one MDX directory into a static React documentation site. Vite powers development and the client build, while `@amamo/mdx` owns content compilation.

[Start building](/guide/getting-started/) or read about [GitHub Pages deployment](/deployment/).

<Callout>Register React components once and use them directly from any MDX document.</Callout>

## Included in the first release

- Vite SSR during development and static HTML at build time
- Locale-aware routes and metadata
- Pagefind full-text search
- Light and dark themes
- Custom React components in MDX
- Deployment below a subpath such as `/doctrine/`
