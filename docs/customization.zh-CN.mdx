# 自定义

Doctrine 提供两条定制路径：用 CSS 调整外观，用 React 组件映射扩展 MDX。二者都是可选的，并同时作用于开发环境、静态渲染和客户端 hydration。

## 添加主题样式表

将 `styles` 设置为相对项目根目录的 CSS 文件：

```ts
import { defineConfig } from '@amamo/doctrine'

export default defineConfig({
  styles: './docs/theme.css',
})
```

该样式表会在 Doctrine 内置样式之后加载。只需覆盖实际需要的变量：

```css
:root {
  --doctrine-accent: oklch(0.55 0.2 250);
  --doctrine-accent-foreground: white;
  --doctrine-ring: oklch(0.55 0.2 250);
  --doctrine-radius: 0.9rem;
  --doctrine-font-sans: Inter, sans-serif;
  --doctrine-content-width: 52rem;
}

[data-theme='dark'] {
  --doctrine-background: oklch(0.14 0.02 250);
  --doctrine-muted: oklch(0.21 0.02 250);
}
```

### 主题变量

| 变量                           | 控制内容              |
| ------------------------------ | --------------------- |
| `--doctrine-background`        | 页面和表面背景        |
| `--doctrine-foreground`        | 主要文字              |
| `--doctrine-muted`             | 次要表面和 hover 状态 |
| `--doctrine-muted-foreground`  | 次要文字              |
| `--doctrine-border`            | 边框和分隔线          |
| `--doctrine-ring`              | 键盘焦点环            |
| `--doctrine-accent`            | Badge、步骤和选中控件 |
| `--doctrine-accent-foreground` | 强调色上的文字        |
| `--doctrine-radius`            | 控件和表面的统一圆角  |
| `--doctrine-font-sans`         | 网站字体栈            |
| `--doctrine-content-width`     | 正文最大宽度          |
| `--doctrine-sidebar-width`     | 桌面导航宽度          |
| `--doctrine-header-height`     | 吸顶导航高度          |

亮色值写在 `:root`，暗色覆盖写在 `[data-theme="dark"]`。

## 调整布局区域

稳定的 `data-slot` 属性允许主题定位网站外壳，而不依赖 Tailwind class：

```css
[data-slot='header'] {
  box-shadow: 0 1px 0 color-mix(in oklab, var(--doctrine-ring) 25%, transparent);
}

[data-slot='brand'] {
  color: var(--doctrine-accent);
}

[data-slot='content'] {
  letter-spacing: 0.005em;
}
```

网站外壳提供 `header`、`header-inner`、`brand`、`navigation`、`sidebar`、`main` 和 `content`。内置 MDX 组件则使用对应组件名的 kebab-case。

## 内置 MDX 组件

内置组件无需导入或注册。

### Callout 与 Badge

```mdx
<Callout variant="tip" title="可以部署">
  上传 `dist` 前先运行生产构建。
</Callout>

<Badge>稳定</Badge> <Badge variant="outline">预览</Badge>
```

`Callout` 支持 `note`、`tip`、`warning` 和 `danger`。

## 覆盖内置组件

自定义组件在内置组件之后合并，因此同名条目会替换默认实现。可以导入并包装公开组件，不需要重新实现：

```tsx
import type { IDoctrineComponents } from '@amamo/doctrine'
import type { ComponentProps } from 'react'
import { Callout } from '@amamo/doctrine/components'

function BrandedCallout(props: ComponentProps<typeof Callout>) {
  return <Callout className="border-brand" {...props} />
}

export default { Callout: BrandedCallout } satisfies IDoctrineComponents
```

在 `doctrine.config.ts` 中注册：

```ts
export default defineConfig({
  components: './docs/components.tsx',
})
```

自定义组件会同时被打包到 Node.js 渲染和浏览器中。不要在模块初始化或渲染阶段访问浏览器全局变量；应在 effect 或事件处理器中使用。
